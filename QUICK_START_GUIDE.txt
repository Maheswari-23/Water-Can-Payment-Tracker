🎯 5-MINUTE SETUP CHECKLIST

□ STEP 1: CREATE GOOGLE SHEET
  → Go to sheets.google.com
  → Click "+ Blank"
  → Name it "Water Can Payment Tracker"

□ STEP 2: ADD COLUMN HEADERS (Row 1)
  A1: Customer Name
  B1: Phone Number
  C1: Address
  D1: Number of Cans
  E1: Price Per Can
  F1: Total Amount
  G1: Paid Status
  H1: Payment Date
  I1: Last Reminder Date
  J1: WhatsApp Link

□ STEP 3: ADD FORMULAS

  In F2 (Total Amount):
  =IF(AND(D2<>"", E2<>""), D2*E2, "")

  In J2 (WhatsApp Link):
  =IF(AND(A2<>"", B2<>"", G2="No"), "https://wa.me/91"&SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(B2," ",""),"-",""),"(","")&"?text="&ENCODEURL("Dear "&A2&", your pending water can payment is ₹"&F2&". Kindly make payment. Thank you."), "")

  → Drag both formulas down to row 100

□ STEP 4: ADD DATA VALIDATION
  → Select G2:G100
  → Data → Data validation
  → List of items: Yes,No
  → Save

□ STEP 5: ADD APPS SCRIPT
  → Extensions → Apps Script
  → Delete existing code
  → Paste code from WaterCanPaymentSystem.gs
  → Save
  → Run "onOpen" function
  → Grant permissions

□ STEP 6: REFRESH & APPLY FORMATTING
  → Refresh sheet (F5)
  → Click: 💧 Water Can System → Refresh Conditional Formatting

✅ DONE! Your system is ready!

📱 HOW TO USE
═══════════════════════════════════════════════════════════════════

ADD CUSTOMER:
1. Enter customer details in new row
2. Total Amount calculates automatically
3. Select "No" for Paid Status
4. WhatsApp Link generates automatically

SEND INDIVIDUAL REMINDER:
1. Find unpaid customer (RED row)
2. Click WhatsApp Link in column J
3. WhatsApp opens with pre-filled message
4. Click Send

SEND BULK REMINDERS:
1. Menu: 💧 Water Can System → Send Reminders to All Unpaid
2. New sheet opens with all reminder links
3. Click each link to send

MARK AS PAID:
1. Change Paid Status to "Yes"
2. Enter Payment Date
3. Row turns GREEN automatically

GENERATE REPORT:
1. Menu: 💧 Water Can System → Generate Payment Summary
2. View total revenue, pending amount, collection rate

🆘 QUICK TROUBLESHOOTING
